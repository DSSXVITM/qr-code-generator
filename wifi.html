How to make a QR code for Wi-Fi

Free, private, no app required — guests connect with one scan.

A Wi-Fi QR code lets visitors join your network by scanning, instead of typing a long password. It works on virtually every modern phone and is perfect for cafés, homes, events and offices.

Steps

  1. Open QRVolt and choose the Wi-Fi tab.
  2. Network name (SSID) — type exactly what appears in the Wi-Fi list.
  3. Encryption — pick WPA/WPA2 (most common), WEP, or “open” if there is no password.
  4. Password — paste the network key. Tick “Hidden” only if the SSID is not broadcast.
  5. Generate & download as PNG, SVG or PDF, then print or display it.

Tips for a reliable scan

Use high error correction (H) if you add a logo, keep a clear quiet zone, and test the code with a phone before printing. Place the sign where the camera can focus — good lighting and a matte surface beat glossy plastic.
